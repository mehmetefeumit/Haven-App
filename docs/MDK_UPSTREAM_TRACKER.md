# MDK upstream tracker

Haven uses what MDK provides. When Haven has to work around a gap in the MDK it
pins (a bug, or a feature that is missing but will most likely land upstream),
the workaround is recorded here as MDK's gap rather than as Haven's design
(owner directive, 2026-09-28). One row per mitigation. A row leaves this table
only in the change that deletes the workaround, and only once its removal
condition has been verified, never assumed.

Pinned MDK: v0.10.4 (`fcc85edd`). Upstream releases are tagged `marmotkit-v*`.
